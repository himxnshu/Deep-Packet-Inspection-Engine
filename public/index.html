Multi-Stage Concurrent Inspection Architecture

Traffic is ingested via binary PCAP reader, canonicalized across symmetric conversations, load-balanced via round-robin queues, and processed by isolated Fast Path inspection cores.

Stage 01
PCAP Reader
Decodes raw binary pcap global & packet headers with native struct unpack.
Stage 02
5-Tuple Hasher
Computes canonical hash so both directions map to the same worker core.
Stage 03
LB Worker Pool
Dispatches packet jobs across designated Fast Path thread queues.
Stage 04
Fast Path Cores
Deep payload parse: TLS Client Hello SNI, HTTP Host & DNS labels.
Stage 05
Policy Sink
Enforces drop/forward rules and writes sanitized output PCAP capture.
